# itops-interactive-quote — Antigravity Skill

## Purpose
Perform live commercial negotiations with clients using an interactive HTML5 simulator to adjust hardware margins, hourly rates, and SLA discounts with real-time Gross Operating Margin (MOL) feedback.

## Available Commands
```powershell
# Calcolo margini deterministico da CLI
.\it-ops.cmd quote <slug> calculate

# Generazione Simulatore Interattivo HTML5
.\it-ops.cmd quote <slug> ui
```
